# 🚌 Bus Reservation System

A full-stack Bus Reservation System developed using PHP, MySQL, HTML, CSS, and JavaScript.

The system allows passengers to explore available routes, register and log in, book bus seats, and manage their reservations. Administrators can manage buses, routes, seats, bookings, and payments.

## 🚀 Features

### 👤 Passenger

- Passenger registration
- Passenger login
- Browse available routes
- View bus information
- Seat selection
- Bus ticket booking
- Booking management
- Payment information
- Passenger dashboard

### 👨‍💼 Admin

- Admin login
- Admin dashboard
- Manage buses
- Manage routes
- Manage seats
- Manage passengers
- Manage bookings
- Manage payments

### 🗄️ Database

The project uses MySQL/MariaDB and contains the following main tables:

- `admin`
- `passenger`
- `bus`
- `route`
- `seat`
- `booking`
- `payment`

The database schema is provided in:

`bus_reservation.sql`
